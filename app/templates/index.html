System Architecture & Core Capabilities

⚖️

Rule-Based Priority Scoring

Multi-variable ranking algorithm combining severity (35%), urgency (25%), category criticality (25%), and environmental/weather risks (15%) to automatically rank tickets from 0 to 100.

🏗️

Work Order Management

Direct assignment of engineering units, task forces, and contractors. Track milestone progress sliders, completion target dates, and financial budgets.

📦

Logistics & Inventory Control

Real-time tracking of critical border repair materials: cold-mix asphalt, modular Bailey bridge panels, solar inverters, and heavy machinery with automated minimum-threshold restock alerts.

📊

Analytics & Executive Dashboard

Real-time status breakdowns, sector-wise issue heat maps, category distribution charts, and one-click CSV report exports for administrative briefings.

🛡️

Security & Parameterized SQL

Zero SQL injection vulnerabilities via prepared queries, Werkzeug scrypt password hashing, session-based CSRF defense, and comprehensive audit trail logging.

☁️

Cloud & Vercel Ready

Modular WSGI app structure compatible with Vercel serverless functions and hosted MySQL databases (TiDB, PlanetScale, Azure Database for MySQL).
